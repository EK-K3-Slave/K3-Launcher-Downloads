# K3 Studios Launcher Downloads

Official download host for the K3 Studios Launcher and our games.

## What is here
This repository only holds downloadable builds, release notes and the small files the launcher reads to check for updates. It contains no source code.

## Games
| Game | Status |
|------|--------|
| Hollowcrown | Beta playtest |

## How to play
1. Open the **Releases** page (right side of this page).
2. Download the latest K3 Studios Launcher.
3. Extract it, run it, and press Install, then Play.

The launcher updates the game for you. When a new version is out, the Play button turns into Update.

## Playtesters
Hollowcrown is in Beta, so expect bugs. Report them in our Discord server's bug-reports channel.

Windows may show a "Windows protected your PC" screen the first time. Click More info, then Run anyway.
